# **App Name**: PunjabReliefConnect

## Core Features:

- Relief Request Submission: Allow affected villages to submit their needs (food, water, shelter, etc.) and urgency level through a form.
- Volunteer Dashboard: Display a dashboard with a table of villages, their needs, and urgency levels.
- Interactive Map: Visualize affected villages on a map with color-coded markers based on urgency.
- AI-Powered Summary Generation: Generate concise summaries of village needs using a generative AI tool, to help volunteers quickly understand the situation.
- User Authentication: Implement anonymous user authentication to track form submissions.
- Real-time Data Updates: Update the dashboard and map in real-time as new relief requests are submitted.

## Style Guidelines:

- Primary color: Earthy blue (#558BBD) to evoke trust and stability.
- Background color: Light gray (#F0F4F8), almost white, to give emphasis to the content.
- Accent color: Muted orange (#D8AB6F) to highlight key actions.
- Body and headline font: 'Inter' (sans-serif) for a clean and modern look.
- Use clear and simple icons to represent different needs (food, water, shelter, etc.).
- Use a responsive layout to ensure the application is accessible on all devices.
- Use subtle transitions and animations to improve the user experience.
